# 사용한 외부 에셋과 라이선스

## 음성 (내레이션)
- Microsoft Edge 신경망 TTS, 음성 `ko-KR-SunHiNeural`(여성), `edge-tts` 7.3.1로 생성, rate −4%. 무료. 실존 인물 음성 복제 아님.
- 파일: `assets/voice/n01.wav` … `n09.wav`, 단어 시각 `assets/voice/lines.json`
- 발음 교정: 화면 PIMS / 음성 "핌스", A4 / "에이포", PDF / "피디에프"
