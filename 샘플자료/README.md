# 설비관리 점검용 샘플자료

`node scripts/make-sample-xlsx.js` 로 다시 만들 수 있습니다.
테스트는 **실제 쓰는 지사 말고 빈 지사**(예: 강남지사)를 골라서 하세요.
업로드한 계획은 보수계획 화면의 휴지통으로 파일 단위로 되돌릴 수 있습니다.

## 보수계획 엑셀 (보수계획 화면 → "등록할 파일의 분야" 고르고 업로드)

### 01_보수계획_기계_판정분기.xlsx — 분야: 기계
판정 로직의 모든 분기를 한 파일에 담았습니다. 대상 연도 **2026년** 기준 기대 결과:

| 설비 | 기대 판정 | 확인 포인트 |
|---|---|---|
| 급수펌프 | 필수 (도래) | 2024 보수 + 2년 주기 = 2026 |
| 순환펌프 | 필수 (기한초과) | 2024년이 기한, 2년 경과 문구 |
| 냉각수펌프 | 불필요 (미도래) | 다음은 2028년 |
| 소방펌프 | 선택 (필요시) | "판단 필요" 배지 |
| 드레인펌프 | 선택 (조건부 주기) | 실내 3년 / 실외 2년 안내 |
| 주증기밸브 | 필수 (도래) | "계획 A급" 배지도 함께 표시 |
| 바이패스밸브 | 선택 (이력 없음) | 직전 보수 이력 없음 |
| 안전밸브 | 불필요 (주기 없음) | 판정 불가 안내 |
| 드레인밸브 | 참고(O/H 외) | 시행방법 경상정비 |
| 계장용 밸브 | 참고(O/H 외) | 필요시지만 배너 집계에서 제외 |
| 소화설비 점검 | 참고(O/H 외) | 시행방법 소방용역 |

- 탭 숫자 기대값: **필수 3 · 선택 3 · 불필요 2 · 참고(O/H 외) 3**
- 상단 배너 "사용자 판단이 필요한 항목"은 **3건**(선택 탭과 일치해야 함)
- 필수 3건이 자동 체크되어 "선택됨 3"
- 시행방법 열: O/H 항목은 **O/H 배지**, 나머지는 경상정비/경상보수/소방용역

### 02_보수계획_전기_설비명엣지.xlsx — 분야: 전기
설비명 정규화를 봅니다. 설비 마스터에 아래 이름으로 등록되어야 합니다.

- `4. 6.9kV SWGR 고압반` → **6.9kV SWGR 고압반** (❌ "9kV SWGR 고압반"이면 버그)
- `5. 460V LOAD CENTER 저압반` → **460V LOAD CENTER 저압반**
- `11. 수배전설비` → **수배전설비**
- 154kV GIS: 주기 문구에 "4년"이 두 번 나오지만 값이 같으므로 **조건부가 아닌 4년 주기**로 읽혀야 함
  (서로 다른 숫자가 섞이면 그때는 "선택"으로 빠집니다 — 01번의 드레인펌프가 그 경우)

### 03_보수계획_제어_소규모.xlsx — 분야: 제어
설비 마스터의 **분야 필터**(기계/전기/제어) 확인용입니다.
01·02와 함께 올린 뒤 칩을 눌러 장기 계획 표와 설비 목록이 같이 걸러지는지 보세요.

## 수량산출서 엑셀 (업로드 분석 화면)

### 04_수량산출서_일정있음.xlsx
시트명이 "기계 (GT·ST)"인데도 **행 내용 기준으로** 설비가 갈려야 합니다.

- 추출 **10건**, 제외 **3건**(소계·직접비·합계)
- 설비 분류 기대값: GT 2 · ST 1 · HRSG 1 · DH 1 · 펌프/밸브 1 · 배관 1 · 전기설비 1 · 제어설비 1 · 비계 1
  (전부 GT로 쏠리면 시트명 우선 버그)
- 작업시작일·종료일이 그대로 저장되어 **공정표에 엑셀 일정대로 배치**되는지
- Tag No.(P-101, TR-01, PIT-7610) 저장 여부

### 05_수량산출서_일정없음.xlsx
예정일 컬럼이 없습니다. 공정표에서 **작업명 키워드로 자동 배치**되는지 봅니다.
분해 → 점검 → 조립 → 시운전 순서로 기간 앞뒤에 퍼져야 하고,
공정표 각 행의 일정 출처가 "지정"이 아니라 자동배치로 표시됩니다.

### 06_수량산출서_확인필요.xlsx
- **원가계산서 시트는 통째로 제외**되어야 합니다 (추출 0건)
- "공사내역 (기계)" 시트에서 **4건 추출, 그중 2건이 확인 필요**
  - GT 연소기 점검 → 수량이 "일부"라 숫자로 못 읽음 (수량 불명확)
  - HRSG Drum 내부점검 → 단위 칸이 비어 있음 (단위 없음)
- 참고: 수량과 단위가 **둘 다** 없는 행은 작업항목이 아니라고 보고 아예 제외됩니다

## 이어서 점검하면 좋은 순서

1. 보수계획 업로드 → 탭·배너·판정 근거 확인
2. 파일명 클릭 → **원본 엑셀 다운로드** 되는지
3. 설비 마스터 → 설비 자동 등록·분야 필터·연도 축(계획 전체 연도)
4. 설비 행 클릭 → **기기·태그가 그 행 바로 아래** 펼쳐지는지
5. 회차 관리에서 계약기간 입력 → 업로드 분석으로 04번 파일 등록
6. 공정표 → 엑셀 일정대로 배치·오늘 기준선·지연 표시
7. 실적 입력(누계 **수량**으로 입력) → 공정표·대시보드·보고서 반영
