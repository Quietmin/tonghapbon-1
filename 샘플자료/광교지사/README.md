# 광교지사 검증용 샘플자료

`node scripts/make-gwanggyo-sample.js` 로 다시 만들 수 있습니다.

강남지사 샘플(보수계획 39건·작업 34건)은 흐름 점검용이라 작습니다. 이 묶음은
**실제 열병합발전소 한 곳 분량**으로 만들었습니다 — 보수계획 **234건**, 작업 **178건**.

> 사양·제작사·태그는 실제처럼 만든 **가상 값**입니다. 광교지사의 실제 설비 대장이 아닙니다.

비계 설치·해체 4건과 종합시험·루프 점검·종합 시운전 3건을 더한 것입니다.

## 전체 흐름 점검 순서

### 0. 준비 — 지사·회차
1. 설비 마스터 → **광교지사** 선택
2. 회차는 **이미 맞춰 두었습니다** — 운영의 광교 회차 "2026년 정기 오버홀"이
   **계약기간 `2026-11-05` ~ `2026-12-18`** 입니다(2026-11-03 수정, 작업·보수계획 0건).
   광교는 아직 착수 전(수량산출 → 실적 입력 단계)이라 계약기간을 미래로 잡았습니다.
   새 회차를 만들 필요 없이 바로 1단계로 가면 됩니다.
   (수량산출서의 작업기간이 전부 이 안에 있습니다. 실제 범위 11-05 ~ 12-17)

### 1. 보수계획 등록 (3개 파일 또는 통합 1개)
오버홀 수량산출 화면에서 **"등록할 파일의 분야"를 "전체"로 두고** 올립니다(기본값).
분야별 파일 3개를 한꺼번에 넣어도, `통합_01_중장기보수계획.xlsx` 하나만 넣어도 됩니다 — 시트 이름으로 분야가 나뉩니다.
특정 분야(기계·전기·제어)를 고르면 그 파일의 설비가 전부 그 분야로 저장됩니다.
올리고 나면 드롭 영역 아래에 "등록됨: 기계 103 · 전기 62 · 제어 69"처럼 분야별 건수가 나옵니다.

확인할 것 (대상 연도 2026)
- 탭 숫자가 **필수 171 · 선택 3 · 불필요 50 · 참고(O/H 외) 10** 이어야 합니다 (분야 '전체' 기준)
- **선택 3건**은 일부러 넣은 판단 필요 항목입니다 — 모두 기계, 10. 건물·부대설비
  - 터빈건물 지붕 방수 점검 — 조건부 주기 ("실내: 3년 주기, 실외: 2년 주기")
  - 배수로 준설 — "필요시"
  - 방음벽 점검 — 보수 이력 없음
- **참고 10건**은 경상정비·용역 설비입니다 (공기압축기, 천장크레인, 비상조명, 접지저항 등)
- 기한초과 14건은 판정 근거가 "○년 보수 + ○년 주기 → ○년 도래(○년 초과)"로 보여야 합니다

### 2. 설비 마스터 확인
- 대분류 기준으로 **기계 10 · 전기 7 · 제어 7 = 24개** 설비가 자동 등록됩니다
  (수량산출서까지 올리면 3단계에서 10개가 더 붙어 34개가 됩니다)
- 설비별 전체 현황의 전체 설비 수가 **234**여야 합니다

### 3. 수량산출서 등록 (3개 파일 또는 통합 1개)
작업·공정 → 엑셀 등록에서 올립니다. 분야는 **전체**(자동 판별)로 두면 됩니다.
분야별 파일 3개를 넣어도, `통합_02_수량산출서.xlsx` 하나만 넣어도 결과가 같습니다.

확인할 것
- 추출 **178건**, 제외 **7건**(공종 시트 끝의 소계 행), 확인 필요 **0건**
- **원가계산서 시트는 통째로 건너뛰어야** 합니다 (작업으로 잡히면 버그)
- 설비 분류

  | 설비 | 건수 | 설비 | 건수 |
  |---|---|---|---|
  | GT | 12 | 전기설비 | 36 |
  | HRSG | 14 | 발전기 | 11 |
  | ST | 14 | 제어설비 | 46 |
  | 펌프/밸브 | 16 | DH | 9 |
  | 배관 | 3 | 비계 | 4 |
  | 기타 | 13 | | |

  > **기타 13건**은 대부분 첨두부하보일러(버너·송풍기·연소안전장치)와 냉각탑 팬입니다.
  > 앱의 설비 분류에 보일러·냉각탑 범주가 없어서 생기는 결과로, 버그가 아니라 현재 동작입니다.
- 설비 마스터에 **설비 유형 10개**가 추가됩니다 — GT·HRSG·ST·펌프/밸브·DH·배관·비계·전기설비·발전기·제어설비.
  '기타'는 분류 실패라는 뜻이라 마스터에 만들지 않습니다. 보수계획 대분류 24개와 합쳐 **34개**가 되어야 합니다

### 4. 공정표
- 모든 작업이 엑셀에 적은 날짜 그대로 배치됩니다 (자동배치 0건)
- 계약기간이 11-05부터라 **11-04 이전에 올리면 착수했어야 할 작업이 0건** — 전부 "대기"로 나오고 지연도 0건입니다.
  착수일이 지난 뒤에 실적을 안 넣은 작업은 **지연**으로 바뀝니다 (지연 기준: 계획 진도 − 실적 ≥ 15%p)

  | 날짜 | 착수 예정일이 지난 작업 |
  |---|---|
  | 2026-11-04 까지 | 0 / 178 |
  | 2026-11-05 | 2 / 178 |
  | 2026-11-15 | 75 / 178 |
  | 2026-11-25 | 137 / 178 |
  | 2026-12-05 | 168 / 178 |

### 5. 실적 입력 → 대시보드·보고서
실적은 퍼센트가 아니라 **누계 수량**으로 넣습니다. 예:
- "가스터빈 흡기필터 교체"(480 EA)에 **240** → 50%
- "HRSG 고압과열기 튜브 두께측정"(1,200 개소)에 **1200** → 100%, 완료
- "6.9kV SWGR 정밀점검"(18 면)에 **6** → 33.3%

> 수량이 큰 작업(튜브 1,200개소·복수기 튜브 12,000본·흡기필터 480EA 등)이 섞여 있어
> **물량 가중 공정률**이 작업 수 기준 체감과 크게 다를 수 있습니다. 이 차이를 보는 것도 검증 포인트입니다.

### 6. 되돌리기
보수계획·업로드 분석 화면의 휴지통으로 파일 단위로 지우면 그 파일에서 나온
계획·작업이 함께 지워집니다. 설비 마스터의 설비는 남으므로, 완전히 비우려면
설비 목록에서도 지워 주세요.
