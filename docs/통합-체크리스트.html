쉬운 말 요약

지금 되는 것7
  • 원본 3개를 지우지 않고 legacy 폴더로 옮겨두고, 통합 앱 자리를 만들었다
  • 통합 앱이 실제로 뜬다 (Next.js 16 · React 19 · TypeScript · Tailwind 4)
  • PlantSync 디자인이 색·글자·유리카드까지 그대로 옮겨졌다
  • 메인 메뉴 3개와 화면 주소 13개가 전부 연결돼 눌러서 돌아다닐 수 있다
  • 배포용 빌드가 통과한다 (화면 15개 전부 정적 생성)
  • Vercel 주소로 열린다
  • DB 설계가 진짜 Postgres에서 돌아간다. 두 번 실행해도 안전하고, 자동 계산 컬럼과 시각 갱신 장치까지 확인했다
반만 된 것6
  • 화면 13개는 열리지만 전부 "포팅 예정"이라는 안내만 있고 내용이 없다
  • 태그를 어떻게 적어도 같은 걸로 찾아주는 기능(PIT-7610 = pit 7610)은 DB에서 확인했지만 쓸 화면이 없다
  • 고장 증상 검색 방법은 정했지만 아직 앱에 넣지 않았다
  • 그 방법으로도 말끝이 바뀐 말(튐 ↔ 튀는)은 못 찾는다. Postgres에 한국어 형태소 분석기가 없어서다
  • 설비 마스터는 설계만 있고 화면도 데이터도 없다
  • 배포된 주소는 로그인 없이 누구나 열린다. 지금은 빈 껍데기라 괜찮지만 실제 자료가 들어가면 문제가 된다
아직 아무것도 안 된 것24
  • 앱이 아직 DB에 연결돼 있지 않다. 무엇을 입력해도 저장할 곳이 없다
  • 설계내역서 엑셀을 올릴 수 없다
  • 작업항목 자동 추출이 안 된다
  • 공정률과 지연 위험이 계산되지 않는다
  • 공정표(간트차트)가 없다
  • 날짜별 실적과 분해 전·후 사진을 넣을 수 없다
  • 일일보고서·경영진 보고서가 안 나온다
  • 고장 이력을 등록할 수 없다
  • 고장 이력을 찾거나 걸러낼 수 없다
  • 고장상보 파일에서 항목을 자동으로 읽어내지 못한다
  • 고장상보를 한꺼번에 올릴 수 없다
  • 첨부파일을 올리거나 받을 수 없다
  • 월별·분야별·설비별 고장 통계가 안 나온다
  • 챗봇에 질문할 수 없다
  • 준공도서 PDF를 올릴 수 없다
  • PDF에서 글자를 뽑아 검색용으로 쌓는 기능이 없다
  • 찾은 근거 문서를 옆에서 미리 볼 수 없다
  • 설비를 등록하거나 목록으로 볼 수 없다
  • 기기·태그를 설비에 붙일 수 없다
  • 설비 하나로 오버홀 작업·고장 이력·준공도서를 함께 보는 화면이 없다
  • 실적 입력에서 고장 이력으로 바로 넘어가는 동선이 없다
  • GitHub에 올려도 자동으로 배포되지 않는다
  • 배포 주소에 접근 제한을 걸지 않았다
  • 배포된 곳에서는 입력한 자료가 남지 않는다

한 줄로: 세 앱이 한 집에 들어올 뼈대와 DB 설계는 끝났고 실제로 돌아가는 것도 확인했다. 다만 안에 들어갈 기능은 아직 한 개도 옮기지 않았다.
