# 발전소 정비 통합 관리 시스템 프로젝트 소개

## 1. 프로젝트 제목
> **발전소 정비 통합 플랫폼** — 정비 공정 관리 · 기술문서 검색 · 고장이력 관리를 하나로 묶은 웹 시스템

## 2. 프로젝트 소개
- **무엇을 만드나:** 발전소 정비(오버홀) 업무에 필요한 세 가지 기능 — ① 공정 진행 관리, ② 기술문서 검색 챗봇, ③ 고장이력 관리 — 를 하나의 웹 프로그램으로 통합합니다.
- **누구를 위해:** 발전소 정비 현장의 관리자·담당 작업자·열람자, DCS/열원설비 정비 인력.
- **왜 (어떤 문제를 해결):** 지금은 공정 진행, 기술문서 찾기, 고장이력 정리가 서로 따로 흩어져 있습니다. 이를 한 곳에 모아 "현재 공정을 관리하다가 → 필요한 기술문서를 바로 찾고 → 과거 고장이력까지 확인"하는 흐름을 끊김 없이 지원합니다.

> 엑셀 설계 문서를 자동 분석해 공정 진행률을 시각화하고(기능①), PDF 등 기술문서를 검색해 출처와 함께 근거 페이지를 보여주며(기능②), 열원설비의 과거 고장이력을 등록·검색·통계로 관리(기능③)하는 통합 시스템입니다.

## 3. 사용자 흐름
> 사용자가 서비스를 쓰는 순서를 **그림**으로 표현합니다. (화면 캡처, 손그림 사진, 화살표 도식 등 무엇이든 좋습니다.)
>
> 예) 접속 → 로그인 → [공정 관리] 진행률 확인 → [문서 검색] 관련 기술문서 조회 → [고장이력] 과거 사례 확인 → 실적 입력 → 리포트 생성

`[여기에 이미지 첨부]`

## 4. 기술 스택
- **프론트엔드:** React 18 + Vite (공정 관리), Next.js (문서 검색 · 고장이력), Tailwind CSS
- **백엔드:** FastAPI (Python 3.10+, 문서 검색 엔진) / 공정 관리는 프론트엔드 전용
- **데이터베이스 / 기타:** ChromaDB(벡터 DB, 문서 검색), SQLite(고장이력), 브라우저 IndexedDB(공정 관리 데이터)
- **사용 도구·서비스:** SheetJS(엑셀 파싱), PyMuPDF(PDF 추출), sentence-transformers(임베딩), React-PDF(문서 미리보기), Stitch(화면 설계), Vercel · Render(배포)

## 5. 진행 상황
- **전체 단계:** 기획 – 화면설계 – 개발 – (기능 통합) – 테스트 – 배포
- **현재 위치:** 세 기능이 개별 폴더로 개발되어 있고, 이제 하나의 프로그램으로 **통합**하는 단계
- **완료된 것:**
  - **기능① 공정 관리 (PlantSync Pro):** 엑셀 자동 분석 엔진(최대 64개 시트, 필드 자동 분류), 대시보드(진행률 시각화), 작업 관리(검색·필터), 간트 차트 일정, 사진 포함 실적 입력, 일일/경영진 리포트
  - **기능② 기술문서 검색 (CheonJae-DDasomi):** PDF 벡터·키워드 검색, 다중 포맷(PDF·HWP·Excel) 색인, 증분 색인, 출처(파일명·페이지) 표기, PDF 미리보기
  - **기능③ 고장이력 관리:** 고장 사례 등록·검색, 통계 분석, 파일 첨부, 화면 설계(와이어프레임) 완료
- **진행 중인 것:** 세 기능을 하나의 시스템으로 합치기(공통 UI·로그인·데이터 연동), 권한별 접근 제어

## 6. 현재 문제
- **막힌 점 (기술·기능):**
  - 세 기능이 서로 다른 스택(React/Vite, Next.js, FastAPI)으로 되어 있어 하나로 합치는 구조 설계가 어려움
  - 데이터 저장소가 제각각(IndexedDB · SQLite · ChromaDB) → 통합 시 사용자·데이터 연동 방식 정리 필요
  - 로그인/권한 관리가 아직 없어 통합 시 공통 인증 체계 필요
- **강사 / 수업에 요청:** *(배우고 싶은 것, 필요한 도움)*
  - 여러 프론트엔드(React/Next.js)와 백엔드(FastAPI)를 하나의 시스템으로 통합하는 아키텍처 설계 방법
  - 공통 로그인/권한(인증) 구현 방법
  - 서로 다른 DB를 함께 쓰거나 통합하는 전략

## 7. 다음 계획
- 세 기능을 하나의 프로그램으로 통합 (공통 레이아웃·내비게이션·로그인)
- 공통 인증/권한(관리자·작업자·열람자) 체계 구현
- 데이터 연동 및 통합 백엔드/DB 구조 정리
- 통합 후 테스트 및 배포(Vercel · Render) 안정화
