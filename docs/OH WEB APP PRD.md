# 발전소 오버홀 공정관리 웹앱 PRD

## 1. 서비스 개요

본 시스템은 발전소 정기 오버홀 기간 중 기계·전기·제어 분야의 공정 현황을 효율적으로 관리하기 위한 웹 기반 공정관리 시스템이다.

관리자가 오버홀 설계내역서 엑셀 파일을 업로드하면 시스템은 설비명, 구성품, 규격, 수량, 단위 정보를 자동으로 추출하여 공정관리용 작업항목으로 변환한다. 이후 분야별 담당자가 하루 1회 실제 완료 물량을 입력하면 시스템은 물량 기준 공정률, 설비별 진행률, 분야별 진행률, 계획 대비 실적, 입력 누락 현황, 지연 위험 공정을 자동 산정하고 대시보드와 보고서로 시각화한다.

본 시스템의 가장 중요한 목적은 직원이 엑셀 내역서를 별도로 가공하지 않아도, 업로드만으로 오버홀 공정관리 화면이 자동 생성되도록 하는 것이다.

---

## 2. 개발 목적

### 2.1 업무상 문제점

현재 오버홀 공정관리는 설계내역서, 공정표, 실적관리표, 보고자료가 분리되어 있어 다음과 같은 문제가 발생한다.

1. 설계내역서 엑셀을 공정관리용 자료로 다시 정리해야 한다.
2. 설비별, 분야별 작업 현황을 한눈에 보기 어렵다.
3. 일일 실적 입력 누락 여부를 수작업으로 확인해야 한다.
4. 실제 물량 기준 공정률 산정이 번거롭다.
5. 경영진 보고자료와 일일보고서를 매번 별도로 작성해야 한다.
6. 분해 전/후 사진이 작업항목과 연결되지 않아 관리가 어렵다.

### 2.2 시스템 도입 목표

1. 설계내역서 업로드만으로 작업항목 자동 생성
2. 설비별·분야별 공정 현황 자동 시각화
3. 실제 완료 물량 입력 기반 공정률 자동 계산
4. 입력 누락 및 지연 위험 공정 자동 알림
5. 일일보고서, 경영진 보고서, 엑셀 다운로드 자동 생성
6. 분해 전/후 사진을 작업항목별로 체계적으로 관리
7. PC와 모바일 모두에서 사용 가능한 외부 접속형 웹앱 구축

## 3. 적용 범위

### 3.1 대상 업무

발전소 연간 정기 오버홀 공정관리 업무

### 3.2 대상 분야

| 분야 | 포함 범위 |
|---|---|
| 기계 | GT, ST, HRSG, DH, 펌프, 밸브, 배관, 보조설비 등 |
| 전기 | 발전기, 차단기, 변압기, 수배전설비, 전동기, 계전기 등 |
| 제어 | DCS, PLC, 계측기, 전송기, 밸브 포지셔너, 제어반 등 |

### 3.3 오버홀 기간

일반적으로 약 20~30일을 기준으로 한다.  
단, 프로젝트별로 시작일과 종료일을 관리자가 직접 입력할 수 있어야 한다.

### 3.4 작업 항목 수

작업 항목 수는 오버홀 규모 및 설계내역서 구성에 따라 달라지므로 제한하지 않는다.  
시스템은 수십 건부터 수천 건까지 처리 가능해야 한다.

## 6. 엑셀 설계내역서 자동분석 기능

### 6.1 기능 개요

관리자가 오버홀 설계내역서 엑셀 파일을 업로드하면 시스템은 각 시트를 분석하여 공정관리 대상 작업을 자동 추출한다.

엑셀에는 설비별 구성품, 규격, 수량, 단위가 포함되어 있으며, 일정 정보는 포함되어 있지 않다. 따라서 시스템은 엑셀에서 작업항목을 추출한 후 별도의 오버홀 기간 정보를 기준으로 공정표 초안을 생성해야 한다.

### 6.2 업로드 대상 파일

다음 유형의 엑셀 파일 업로드를 지원한다.

1. 기계 분야 설계내역서
2. 전기 분야 설계내역서
3. 제어 분야 설계내역서
4. 기계·전기 통합 설계내역서
5. 제어 대상기기 LIST

### 6.3 자동 인식 대상 컬럼

시스템은 엑셀 내 컬럼명을 기준으로 아래 정보를 자동 인식해야 한다.

| 인식 항목 | 예시 컬럼명 |
|---|---|
| 분야 | 기계, 전기, 제어, 시트명 기반 자동 판단 |
| 설비명 | GT, ST, HRSG, DH, 발전기, 제어설비 등 |
| 구성품명 | 명칭, 품명, Description |
| 규격 | 규격, Specification, Range |
| 수량 | 수량, Qty |
| 단위 | 단위, Unit |
| 비고 | 비고, Remark |
| 태그번호 | Tag No., Tag Number |
| 시트명 | 원본 시트명 |
| 원본 행번호 | 엑셀 원본 행번호 |

### 6.4 자동 제외 대상 행

설계내역서에는 실제 작업항목이 아닌 제목, 소계, 합계, 헤더 행이 포함될 수 있다.  
시스템은 아래 유형의 행을 자동 제외해야 한다.

| 제외 대상 | 예시 |
|---|---|
| 제목행 | 직접비 설계내역서, 공사 설계내역서 |
| 헤더행 | 항목, 명칭, 규격, 수량, 단위 |
| 소계행 | 소계, 계 |
| 합계행 | 합계, 총계 |
| 빈 행 | 값이 없는 행 |
| 금액 중심 행 | 재료비, 노무비, 경비, 합계만 있는 행 |
| 원가계산 행 | 제비율, 일반관리비, 이윤 등 |

### 6.5 작업항목 인식 기준

아래 조건을 만족하는 행은 공정관리 대상 작업으로 인식한다.

1. 명칭 또는 품명이 존재할 것
2. 수량이 존재할 것
3. 단위가 존재할 것
4. 제목, 소계, 합계 행이 아닐 것
5. 분야 또는 설비 분류가 가능할 것

### 6.6 분야 자동 분류 규칙

시스템은 시트명, 파일명, 작업명, 설비명을 기준으로 분야를 자동 분류한다.

| 분야 | 판단 기준 |
|---|---|
| 기계 | GT, ST, HRSG, DH, 펌프, 밸브, 배관, 터빈 등 |
| 전기 | 발전기, 변압기, 차단기, MCC, 전동기, 절연, 계전기 등 |
| 제어 | DCS, PLC, Transmitter, Tag No., 계측기, 제어밸브 등 |

### 6.7 설비 자동 분류 규칙

설비는 우선 시트명으로 1차 분류하고, 작업명 및 구성품명으로 2차 분류한다.

| 설비 분류 | 키워드 예시 |
|---|---|
| GT | GT, Gas Turbine, 가스터빈 |
| ST | ST, Steam Turbine, 증기터빈 |
| HRSG | HRSG, 배열회수보일러 |
| DH | DH, 지역난방, 열공급 |
| 발전기 | Generator, 발전기 |
| 전기설비 | 차단기, 변압기, MCC, 전동기 |
| 제어설비 | DCS, PLC, Transmitter, 계측기, 제어밸브 |

### 6.8 자동분석 결과 확인 화면

엑셀 업로드 후 시스템은 다음 정보를 표시해야 한다.

| 항목 | 설명 |
|---|---|
| 업로드 파일명 | 업로드된 엑셀 파일명 |
| 전체 시트 수 | 분석 대상 시트 수 |
| 추출 작업 수 | 공정관리 대상 작업 수 |
| 제외 행 수 | 제목, 소계, 합계 등 제외된 행 수 |
| 분야별 작업 수 | 기계, 전기, 제어별 작업 수 |
| 설비별 작업 수 | GT, ST, HRSG 등 설비별 작업 수 |
| 확인 필요 항목 | 수량, 단위, 설비 분류가 불명확한 항목 |

관리자는 자동분석 결과를 확인한 후 “작업항목 생성” 버튼을 눌러 공정관리 데이터로 확정한다.

## 7. 공정률 산정 기준

### 7.1 기본 원칙

공정률은 물량 기준으로 산정한다.

각 작업항목은 계획수량과 실제 완료수량을 가진다.  
담당자가 실제 완료수량을 입력하면 시스템은 자동으로 작업별 공정률을 계산한다.

### 7.2 작업별 공정률

작업별 공정률은 다음 공식으로 계산한다.

```text
작업별 공정률 = 실제 완료수량 / 계획수량 × 100
```

물량 기준이므로 작업마다 난이도가 달라도 수량이 크면 크게 잡힌다. 이 성질을 그대로 받아들인다 — 가중치를 따로 두면 근거를 설명할 수 없다.

### 7.3 그룹 공정률 (설비별 · 분야별 · 전체)

```text
그룹 공정률 = Σ(완료수량) / Σ(계획수량) × 100
```

완료수량은 계획수량을 넘길 수 없도록 잘라서 더한다. 한 작업의 초과 입력이 그룹 전체를 부풀리지 않게 하기 위해서다.

### 7.4 누적 입력과 정정

담당자는 "그날까지의 누적"을 입력한다. 화면은 "금일 완료분"을 받아 직전 누적에 더해 누적값을 만든다.

작업의 현재 완료수량은 **가장 최근 날짜에 보고한 누적**이다. 기록 중 최댓값이 아니다. 최댓값을 쓰면 한 번 잘못 올라간 수치를 되돌릴 수 없고, 기록을 통째로 지우는 것 말고는 정정 수단이 없기 때문이다.

## 8. 공정표 자동 생성

### 8.1 기능 개요

설계내역서에는 일정 정보가 없다. 그래서 시스템은 오버홀 기간(착수일~준공예정일)을 기준으로 계획일정 초안을 만든다.

### 8.2 계획일정 결정 순서

| 순위 | 근거 | 설명 |
|---|---|---|
| 1 | 지정 일정 | 엑셀에 작업 시작일·종료일이 있거나, 사용자가 공정표에서 직접 지정한 경우 |
| 2 | 자동 배치 | 작업명 키워드로 8.3의 구간에 배치 |
| — | 계산 불가 | 계약기간이 설정되지 않으면 계획일정을 낼 수 없다 |

지정 일정이 있으면 자동 배치를 하지 않는다. 사용자는 공정표 화면에서 자동 배치를 지정 일정으로 바꾸거나, 지정 일정을 지워 자동 배치로 되돌릴 수 있다.

### 8.3 작업명 키워드 자동 배치 구간

전체 오버홀 기간을 1로 볼 때의 시작~종료 비율이다.

| 구간 | 키워드 | 배치 비율 |
|---|---|---|
| 준비·가설·반입 | 준비, 가설, 반입, 설치, 양생, 가설재 | 0.00 ~ 0.20 |
| 분해·개방 | 분해, 개방, 해체, 탈거, 인출, 철거 | 0.05 ~ 0.32 |
| 점검·세정·청소 | 점검, 세정, 청소, 세관, 세척 | 0.15 ~ 0.50 |
| 검사·측정·진단 | 검사, 측정, 진단, 시료, 채취, 교정, 비파괴, NDT, PT, MT, UT | 0.35 ~ 0.62 |
| 교체·정비 | 교체, 정비, 보수, 용접, 가공, 수리, 재생, 오버홀 | 0.40 ~ 0.72 |
| 조립·복구 | 조립, 복구, 재조립, 보온, 결선, 복원, 원복 | 0.60 ~ 0.85 |
| 시험·시운전·확인 | 시험, 시운전, 확인, 기동, 성능, 점화, 통전, loop | 0.80 ~ 1.00 |
| 전기·제어 병행 | (전기·제어 분야의 점검류, 또는 위에 안 걸리는 전기·제어 작업) | 0.10 ~ 0.90 |
| 일반 공정 | (위 어디에도 안 걸리는 기계 작업) | 0.20 ~ 0.85 |

> **검증 필요.** 이 비율은 통합 이전 원본 앱(`legacy/plantsync/src/lib/schedule.js`)에서 그대로 이어받은 값이고, 저장소 안에 산출 근거가 남아 있지 않다. 실제 오버홀 공정과 맞는지 현장 담당자 확인이 필요하다.
> 다만 ① 엑셀에 예정일이 있으면 이 값을 쓰지 않고 ② 공정표에서 사람이 직접 조정할 수 있으므로, 틀렸더라도 되돌릴 수 있다.

### 8.4 계획 공정률

특정 일자의 계획 진척은 그 작업의 계획 구간 안에서 선형으로 오른다고 본다.

```text
작업 계획진척 = 0                                    (계획 시작 전)
             = (오늘 - 계획시작) / (계획종료 - 계획시작) × 100
             = 100                                  (계획 종료 후)

전체 계획공정률 = Σ(계획수량 × 작업 계획진척) / Σ(계획수량)
```

대시보드 상단의 "기간 경과 비율"(단순 선형)보다 정밀하다. 작업마다 계획 구간이 다르기 때문이다.

### 8.5 지연 위험 판정

```text
지연 위험 = 미완료(공정률 < 100) 이고,
           (계획진척 - 실제진척) >= 15%p
```

임계치 15%p는 한 곳(`schedule.ts`)에만 둔다.
